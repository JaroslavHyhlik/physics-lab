# Otázky pro tebe

Sem se zapisují rozhodnutí, která musíš udělat ty. Až odpovíš, otázku smaž nebo označ jako vyřešenou.

## Otevřené

1. **Zveřejnění webu (fáze 1).** Až budeš spokojený/á s ukázkovými simulacemi, potvrď, že mám
   přepnout repozitář `JaroslavHyhlik/physics-lab` na **veřejný** a zapnout GitHub Pages.
   Web pak poběží na `https://jaroslavhyhlik.github.io/physics-lab/` (HTTPS, nutné pro senzory iPhonu).
2. **Kontrola na iPhonu a design.** Po zveřejnění otevři web v Safari na iPhonu a napiš, co se ti
   líbí / nelíbí (barvy, rozložení, velikost písma, ovládání posuvníků prstem).
